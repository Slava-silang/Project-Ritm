# Проект ритм
## Что из себя представляет проект
 Приложения для удобства работы и учёбы. Отслеживание дедлайнов, планирование, создание задач, расписание, контроль внимания, концентрации и продуктивности.
## Основная цель
Помочь пользователю коорденировать свои временем и не забыть о задачах.
## Описание приложения
Десктоп приложение (НЕ НА ЭЛЕКТРОНЕ).
## Обязательные пункты
* Наличие удобного календаря, где видно уже распределенные по дням задачи и мероприятия
* Возможность разбить задачу на подзадачи
* Возможность задать вес задачи и ожидаемое время выполнения
* Возможность контролировать выполнение подзадач и задавать им вес в процентах
* Возможность просмотра дедлайнов с упорядоченностью по близости
* Полоса прогресса, где можно увидеть насколько пользователь продвинулся, например на это неделе
* Режим фокусировки: пользователь назначает старт и конец работы, чтобы отслеживать потраченную на работу время
* Возможность прикрепления файлов, материалов, книг
* Мини компаньон поверх всех приложений с небольщими анимациями (с возможность отключения)
* Комментарии компаньона, например, о том, что пользователь млишком много работает, или похвала за прогресс.
* Агент, который поможет составить задачу по запросу, распределить её на подзадачи и зафиксировать в календаре.
* Скилы для агента
* ВАЖНО: мы не пишем и не запускаем свою модель, мы оставляем на пользователя возможность подключить свою по API, ну потому что нет у нас мощностей и ресурсов.
## Желательные пункты
* Наличие нескольких тем и языков
* МСП: пользователь пишет запрос агенту, чтобы проверить почту/мессенджер, (указав изначально чаты для мессенджера) с целью сбора задач. В последствии агент с подтверждения пользователя усстанавливает это задачи в календаре.
## Возможные пункты
* Интерактивная часть: какой-нибудь сад/дерево, которое растет по мере продвижения по задачам. Короче, что-то декоративное.
