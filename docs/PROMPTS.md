# Промпты для начала и продолжения

Эти задания используют документы в репозитории как источник требований. T01–T20, T12a и T17a уже завершены, включая календарь и фокус-сессии. Для следующего запуска использовать промпт продолжения либо выполнение конкретного этапа T21; первоначальный промпт ниже сохранён как история первого шага.

## Первый запуск разработки — выполненный T01

```text
Начни разработку «Ритма» в текущем репозитории.

Прочитай AGENTS.md, docs/STATUS.md и docs/TASKS.md. Изучи согласованные требования в docs/SPEC.md, архитектурную основу в docs/ARCHITECTURE.md и порядок запуска в docs/DEVELOPMENT.md.

Сверь документы с фактическим состоянием файлов и Git. Выполни T01: подготовь воспроизводимое окружение uv и минимальное запускаемое приложение Python + PySide6 + QML. Используй SQLite для будущего хранения, но ограничь этот шаг критериями T01.

Проверь актуальную совместимость Python и зависимостей, зафиксируй версии. Настрой команды запуска и проверок. Минимальное окно должно запускаться из проекта и при другом текущем каталоге. Пользовательские данные и секреты держи отдельно от исходников.

Выполни подходящие проверки, укажи фактически проверенный стенд и ограничения. Обнови TASKS, STATUS и реальную инструкцию запуска. Сохрани законченный шаг локальным коммитом, сохранив чужие изменения.

На этом первом запуске остановись после T01 и покажи, как запустить окно. Следующий шаг — ранняя упаковка T02. Обращения к платному API и публикация требуют отдельного согласования.
```

## Продолжение после паузы или окончания лимита

```text
Продолжи проект «Ритм» в текущем репозитории.

Следуй AGENTS.md. Прочитай docs/STATUS.md и текущую задачу в docs/TASKS.md, затем связанные разделы SPEC, ARCHITECTURE, DEVELOPMENT и TESTING.

Сверь записанное состояние с текущей веткой, незавершёнными изменениями и реальными результатами команд. После внезапного обрыва сначала установи, какие операции завершились. Сохрани существующие изменения.

Кратко сообщи готовую часть и конкретное действие продолжения. Выполни следующий законченный шаг текущей задачи, проверь его и обнови документы состояния. При продолжении нескольких задач соблюдай их зависимости и приоритеты; после каждого законченного шага сохраняй восстановимое состояние.

Различай пройденные проверки, ручную оценку пользователя и непроверенные платформы. Изменение согласованного поведения и платные запросы согласовывай отдельно.
```

## Самостоятельное выполнение этапа

Вставить ID выбранного этапа/задачи вместо скобок.

```text
Выполни [ID задачи или этапа] проекта «Ритм» по AGENTS.md и документам репозитория.

Перед началом проверь зависимости и текущее состояние. Разбей этап на небольшие законченные шаги с проверяемым результатом. Двигайся по ним самостоятельно, обновляя TASKS и STATUS после каждого шага.

Если обнаружится риск для срока учебной версии, покажи фактически готовое, оставшуюся работу и конкретные варианты переноса функций. Сокращение согласуй с пользователем.

В конце укажи выполненные критерии, проверки, способ запуска и точное следующее действие.
```
