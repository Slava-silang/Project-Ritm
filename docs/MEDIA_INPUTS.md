# T35 — файлы и изображения для помощника

Исследовано 16 ноября 2026 года. Описывает реализованное подключение и его ограничения; не подтверждает доступность каждой модели конкретному аккаунту.

## Официальный способ

Sign in with ChatGPT допускает текст, изображения и файлы, если их принимает выбранная модель. Для этого потока нет Files upload API, аудио/видео-входа, hosted file search и Code Interpreter. Поэтому приложение передаёт содержимое непосредственно в Responses-запросе, не создавая облачную файловую библиотеку. Источник: [ограничения входа через ChatGPT](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations).

Используется публичный `/v1/responses`, модель из каталога аккаунта, `store:false`, `stream:true`, история в текущем `input`. Успех — только после `response.completed`. Источник: [модели и inference](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference).

Для изображений используются `input_image` и data URL; для документов — `input_file` с filename/file_data. Серверная обработка PDF может включать страницы как изображения, обычных документов — извлечённый текст; таблицы обрабатываются особым образом, поэтому отправка файла не обещает полного анализа всех его элементов. Источники: [изображения](https://developers.openai.com/api/docs/guides/images-vision), [файлы](https://developers.openai.com/api/docs/guides/file-inputs).

Поддержка изображения подтверждена страницами [GPT-6.1 Sol](https://developers.openai.com/api/docs/models/gpt-6.1-sol) и [GPT-6 Astra](https://developers.openai.com/api/docs/models/gpt-6-astra). В T35 разрешение бинарных файлов задаётся только для этих точных slug. Другие модели не переключаются автоматически: сохраняется прежний локальный текстовый режим, если он применим. Расширять список после проверки официального контракта; имя похожей модели не означает совместимости. Каталог всё равно ограничивает фактический выбор аккаунтом.

## Правила «Ритма»

- До 5 выбранных файлов на сообщение; бинарный файл до 8 МиБ, сумма до 20 МиБ. Это пределы приложения, а не объявленные пределы сервиса. Изображения — до 12 миллионов пикселей.
- Неподвижные PNG, JPEG и WebP. Документы: PDF, TXT/MD, JSON/HTML/XML, CSV/TSV, DOC/DOCX/ODT/RTF, PPT/PPTX, XLS/XLSX и явно перечисленные в application/media.py исходники. GIF, архивы, исполняемые файлы, аудио/видео и прочие расширения можно хранить, но нельзя отправлять этим способом.
- Для совместимого подключения документы передаются исходными байтами без местного OCR/разбора. Сканированный PDF можно передать целиком; корректность его анализа определяет модель. Предпросмотр/поворот/обрезка только изображений, не документов.
- Для остальных подключений остаётся T26: TXT/MD/PDF с текстовым слоем, отдельный процесс чтения и 60 000 символов суммарно. Тестовый адаптер по умолчанию остаётся текстовым; мультимодальные автотесты используют отдельную подмену.
- Импорт через выбор файла создаёт управляемый материал. Он остаётся локально после отмены разговора, поскольку импорт — отдельное подтверждённое действие. Можно отметить его для сообщения; неподдерживаемый формат не выбирается автоматически.
- Поворот/обрезка в процентах применяются к предпросмотру, затем по отдельной кнопке сохраняется PNG-копия в «Материалы». Оригинал не изменяется. При превышении 8 МиБ предлагается меньший фрагмент.
- Выбранные материалы связываются с главной задачей только вместе с подтверждённым предложением, одной транзакцией. Существующие прямые вложения остаются у прежнего владельца. Отказ ссылки/пропавший материал откатывает изменение задачи. Квитанция учитывает набор материалов, повтор не создаёт дубликатов.
- Файлы прежних сообщений не входят в автоматический контекст. В продолжении обсуждения повторный выбор требует отдельного согласия перед запросом; отказ не вызывает провайдера. Выбор сбрасывается при закрытии/смене контекста/подключения.
- В историю не добавляются base64, байты файлов или data URL предпросмотра. Модель может процитировать присланный материал в своём ответе; это обычный текст ответа.

## Проверка

Автотесты используют временные профили, синтетические изображения/документы и подмены провайдера. Реальная отправка пользовательских файлов/платные API-вызовы в T35 не выполняются. Интерфейс проверяется отдельно на Linux/X11; Windows/Wayland и новая самостоятельная сборка остаются непроверенными.
