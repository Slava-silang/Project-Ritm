# Текущее состояние

Обновлено: 8 ноября 2026 года.

## Этап

P00 и T01 завершены. Есть установленное окружение uv, минимальное приложение Python/PySide6/QML, точки входа `ritm` и `python -m ritm`, тесты запуска и команды проверок. Следующая задача — T02, ранняя самостоятельная упаковка.

## Готовая часть T01

- `pyproject.toml`, `.python-version`, `uv.lock`: Python 3.12, PySide6 6.12.0, pytest 9.2.0, Ruff 0.17.4.
- `.gitignore`: окружение, кеши, секреты, пользовательские базы, локальные данные и сборки исключены.
- `src/ritm/app.py`: настройки приложения, поиск QML относительно модуля, обработка ошибки загрузки, обычный запуск и диагностический `--smoke-test`.
- `src/ritm/qml/Main.qml`: русское стартовое окно и действующая кнопка закрытия. Цвета и композиция временные, финальный дизайн не утверждён.
- `tests/test_startup.py`: запуск обеих точек входа из другой папки с пробелом/кириллицей и временными XDG-каталогами.
- README, DEVELOPMENT, ARCHITECTURE, TESTING, TASKS и PROMPTS приведены к фактическому состоянию.

Исходный README сохранён как описание первоначальной идеи. При расхождении согласованное поведение берётся из SPEC.

## Согласованные границы

Linux достаточен для учебного выпуска; архитектура сохраняет переносимость на Windows. Доступ к Windows не уточнён. MCP отложен. Внешность компаньона будет выбрана позже, используется временная графика. Изменения объёма и поведения, публикация, удаление личных данных и платные API-запросы согласуются отдельно.

Ориентир готовности учебной работы — около 28 ноября 2026 года; оценки этапов уточняются после ранних экспериментов.

## Проверки T01

- `uv run --locked pytest`: 2 passed.
- Ruff check, Ruff format --check, pyside6-qmllint: без ошибок.
- Qt xcb на Linux Mint 22.3, x86_64, Cinnamon/X11: окно реально показано; осмотрены размеры 1000×680 и 640×480; клик по собственной кнопке закрыл окно.
- Команда uv с `--project` проверена из `/tmp` на реальном X11, код выхода 0.
- `uv build --wheel`: Python-пакет создан, Main.qml включён. Это не standalone-поставка; T02 не закрыта.
- Исходный ограниченный запуск X11 не имел доступа к дисплею; проверка в разрешённой пользовательской сессии прошла. Системные библиотеки дополнительно устанавливать не потребовалось.

## Запуск пользователем

Из репозитория: `uv run ritm`. Для воспроизведения окружения: `uv sync --locked`.

## Что ещё не реализовано

Задачи, календарь, таймер, SQLite-хранилище, вложения, резервные копии, ИИ и компаньон относятся к следующим задачам. В T01 окно закрывает процесс; скрытие в трей появится в T21.

Платные API-вызовы не выполнялись. Nuitka и самостоятельная поставка пока отсутствуют. Windows и Wayland не проверены.

Ветка реализации — `codex/bootstrap`, основана на документах `2e9911a`. Локальная фиксация T01 — коммит с сообщением `feat: bootstrap PySide6 QML application`; точный идентификатор брать из Git. Окружение `.venv` и wheel в `dist/` остаются локальными и не коммитятся.
