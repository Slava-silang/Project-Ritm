# Текущее состояние

Обновлено: 8 ноября 2026 года.

## Этап

P00, T01, T02 и T03 завершены. Есть минимальное QML-приложение, самостоятельная Linux-поставка и отдельный проверенный технический прототип компаньона. Следующая задача — T04, модель задач и двух уровней подзадач.

## Готовая часть T01

- `pyproject.toml`, `.python-version`, `uv.lock`: Python 3.12, PySide6 6.12.0, pytest 9.2.0, Ruff 0.17.4.
- `.gitignore`: окружение, кеши, секреты, пользовательские базы, локальные данные и сборки исключены.
- `src/ritm/app.py`: настройки приложения, поиск QML относительно модуля, обработка ошибки загрузки, обычный запуск и диагностический `--smoke-test`.
- `src/ritm/qml/Main.qml`: русское стартовое окно и действующая кнопка закрытия. Цвета и композиция временные, финальный дизайн не утверждён.
- `tests/test_startup.py`: запуск обеих точек входа из другой папки с пробелом/кириллицей и временными XDG-каталогами.
- README, DEVELOPMENT, ARCHITECTURE, TESTING, TASKS и PROMPTS приведены к фактическому состоянию.

Исходный README сохранён как описание первоначальной идеи. При расхождении согласованное поведение берётся из SPEC.

## Согласованные границы

Linux достаточен для учебного выпуска; архитектура сохраняет переносимость на Windows. Доступ к Windows не уточнён. MCP отложен. Внешность компаньона будет выбрана позже, используется временная графика. Изменения объёма и поведения, публикация, удаление личных данных и платные API-запросы согласуются отдельно.

Ориентир готовности учебной работы — около 28 ноября 2026 года; оценки этапов уточняются после ранних экспериментов.

## Запуск пользователем

Из репозитория: `uv run ritm`. Для воспроизведения окружения: `uv sync --locked`.

Самостоятельная сборка: `./dist/ritm-linux-x86_64/ritm.bin`. Архив `dist/ritm-0.1.0-linux-x86_64.tar.gz` нужно переносить и распаковывать целиком, вместе с библиотеками.

## Готовая часть и проверки T02

- Группа packaging: Nuitka 4.2.2, ordered-set, zstandard, Linux patchelf; версии сохранены в lock.
- `src/main.py`, `pysidedeploy.spec`, `scripts/build_linux.py`: standalone, QML относительно модуля, временная рабочая spec, 4 задачи компилятора, встроенный libpython, архив и SHA256.
- `ritm.__version__` — единый источник версии для Hatchling и runtime; зависимость runtime от метаданных установки удалена.
- `scripts/check_linux_build.py` и `packaging/linux/Dockerfile.smoke`: проверка переноса в кириллическую папку и Ubuntu-контейнера без Python/исходников/сети.
- Обнаруженная регрессия Nuitka 4.1.1: SIGABRT до Python-кода в кириллическом пути. Воспроизведена командой relocation-only, после обновления до 4.2.2 проверка проходит.
- Финальный архив проверен по SHA256 и распакован в другой кириллический путь. Проверены QML, отсутствие внешних symlink, реальный запуск X11 и повторные relocation/container-проверки, код выхода 0.
- Размер архива 93 383 160 байт; папка около 288 МиБ. Актуальная контрольная сумма рядом с архивом; локальный отчёт проверки — `build/verification.json`.
- Исходники проходят 2 pytest-теста запуска, Ruff и qmllint. Предел поддержки: проверенный Mint/Cinnamon/X11 и Ubuntu 24.04 runtime-контейнер; Windows и Wayland отдельно не проверялись.

## T03 — результат эксперимента

Ветка `codex/companion-probe`, фиксация `prototype: verify companion window behavior on X11`. `uv run python scripts/companion_probe.py` запускает временного персонажа, правый клик позволяет закрыть. `--verify` открывает собственное проверочное окно, имитирует реальные X11-клики и перенос, проверяет fullscreen и закрывает окна, восстанавливая курсор.

Все пять проверок прошли на Cinnamon/X11: alpha, click-through, верхний слой, перенос, скрытие/возврат при fullscreen. Результат и изображение — локально в `artifacts/t03/`. Код прототипа не подключён к основному приложению и не является готовой реализацией T28. QtQuick-вариант, многомониторность, Wayland и Windows ещё не проверены. Последняя самостоятельная поставка остаётся T02.
