# Тёмная тема «Ритма»

Три макета страницы «Задачи» и диалога «Новая задача» используют один набор демонстрационных данных. В каждом можно оценить читаемость сроков и прогресса, форму кнопок и полей, заметность выбора и клавиатурного фокуса.

| Направление | Экран | Диалог | Отличие |
| --- | --- | --- | --- |
| Графит | [Задачи](previews/graphite-tasks.png) | [Новая задача](previews/graphite-dialog.png) | Мятные акценты, боковая навигация и отдельная поверхность под каждой задачей. Радиусы 12 для элементов и 20 для диалога. |
| Сумерки | [Задачи](previews/dusk-tasks.png) | [Новая задача](previews/dusk-dialog.png) | Сине-серый фон, лавандовый акцент и навигация сверху. По горизонтали больше места для списка. Радиусы 14 и 24. |
| Ночной блокнот | [Задачи](previews/notebook-tasks.png) | [Новая задача](previews/notebook-dialog.png) | Тёплый угольный фон, янтарный акцент, список с тонкими разделителями. Радиусы 10 и 18. |

Графит — предпочтительный исходный вариант. По фоновым поверхностям удобно находить отдельные задачи, а палитра оставляет больше пространства для визуально отличимых «Космоса» и «Джунглей».

## Просмотр

```sh
uv run --locked python docs/design/dark/preview.py
```

Клавиши **1**, **2**, **3** переключают варианты. Нажатие на строку показывает сведения о задаче. **Ctrl+N** или кнопка «+ Задача» открывает диалог и переводит фокус на название. **Esc** закрывает диалог. **Ctrl+Shift+M** переключает уменьшенное движение. Смена состояния кнопок занимает 110 мс, выделение строки — 120 мс. Диалог появляется за 150–170 мс и закрывается за 105 мс. В режиме уменьшенного движения изменения мгновенные.

Образец рассчитан на область 1160×740 и работает отдельно от приложения. Данные в форме демонстрационные. Внедрение выбранного направления включает проверку адаптации на узком окне 640×480, масштабов 100/125/150%, клавиатуры и состояний ошибок на Linux.

## Экспорт

```sh
uv run --locked python docs/design/dark/preview.py --render docs/design/dark/previews
```

Экспорт делает шесть PNG и проверяет клик по созданию задачи, фокус, Esc и открытие с уменьшенным движением. Текущие PNG отрисованы Qt Quick в Windows offscreen с Segoe UI.

Для выбранных сочетаний текста и фона минимальный расчётный контраст составил 5,63:1. У границ полей и вторичных кнопок — 3,18:1. Проверка относится к цветам макета.
