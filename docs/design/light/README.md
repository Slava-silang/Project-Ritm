# Светлая тема «Ритма»

Три варианта используют одинаковые задачи и форму создания. Во всех макетах навигация сбоку, у элементов скругление 12, у окна 20. Форма открывается над рабочей областью справа от панели.

| Вариант | Экран | Форма | Отличие |
| --- | --- | --- | --- |
| 1. Мята | [Задачи](previews/mint-tasks.png) | [Новая задача](previews/mint-dialog.png) | Серо-мятная навигация, белые карточки и глубокий зелёный акцент. По устройству ближе всего к «Графиту». |
| 2. Лён | [Задачи](previews/linen-tasks.png) | [Новая задача](previews/linen-dialog.png) | Тёплые светлые поверхности и терракотовый акцент. Задачи разделены линиями, выбранная строка залита цветом. |
| 3. Небо | [Задачи](previews/sky-tasks.png) | [Новая задача](previews/sky-dialog.png) | Холодный голубовато-серый фон, синие действия и тонированная сводка недели. |

## Просмотр

```sh
uv run --locked python docs/design/dark/preview.py --theme light
```

Клавиши **1**, **2**, **3** переключают варианты. Клик по задаче меняет открытую карточку. **Ctrl+N** открывает форму, **Esc** её закрывает, **Ctrl+Shift+M** переключает уменьшенное движение. Макеты используют демонстрационные данные и работают вне приложения.

Для повторного экспорта шести PNG добавьте `--render docs/design/light/previews`. В образцах минимальный расчётный контраст основных сочетаний текста и фона — 4,80:1, границ полей и вторичных кнопок относительно основных поверхностей — 3,34:1.

Пользователь выбрал «Мяту». В приложении она доступна через «Вид → Светлая → Применить». Раскладка взята из «Графита» и общая для двух тем. В компактном окне навигация переносится наверх. Оформление вкладки «Сад» включает панели, кнопки и диалоги. Подробности проверки — [TESTING D06](../../TESTING.md#d06--мята-в-приложении).
