# Экспорт участка — T39e3

Включить учёт сада, выбрать текущий участок, месяц архива или избранное,
нажать «Экспорт» (↓ в узком окне) и выбрать формат. Обычное окно сохранения
позволяет выбрать папку/имя и подтвердить замену существующего файла.

- **Сад для браузера (HTML)** — один автономный файл. Встроены PNG всего поля,
  таблица растений/украшений со стадиями и расположением, инвентарь, удобрение
  и данные участка. Папка assets, приложение, интернет и JavaScript для
  просмотра не нужны. Оформление страницы фиксированное, в палитре «Сумерек».
- **PNG** — поле целиком с растениями и декором, прозрачным фоном и отступом
  16 исходных пикселей. Масштаб 2× целочисленный, без сглаживания пикселей.
  Кроны входят в границы изображения; выбор/курсор/кнопки/камера не попадают
  в снимок. Вещи из инвентаря перечислены в HTML, на поле PNG их нет.

Это копия выбранного участка для просмотра. Валюта, задачи, письма, настройки
и постоянные достижения не добавляются в файл. Для восстановления рабочего
профиля используется прежняя парная резервная копия (PAIRED_BACKUP.md).
Импорт из HTML/PNG и синхронизация сада в этот пункт не входят.

## Снимок и запись

prepareGardenExport сохраняет immutable Garden, который показан пользователю
при выборе формата. Окно сохранения получает месяц/предлагаемое имя и токен
этого снимка. Смена месяца или обновление поля за время выбора папки не
подменяют содержимое. Отмена удаляет предложение, принятый токен используется
один раз. Поддерживаются только локальные URL без query/fragment.

ui/garden_export.py вызывается последовательным storage-worker. QImage и
QPainter рисуют те же слои garden_scene с проверенными PNG из манифестов,
без QPixmap/снимка окна/рисования в потоке интерфейса. PNG и HTML сначала
полностью формируются в памяти. Затем временный файл в выбранной папке
записывается и fsync/close выполняются до os.replace. Ошибка подготовки,
записи или замены сохраняет прежний файл; собственный временный файл очищается.
Родительская папка должна существовать. Расширение должно соответствовать
формату; defaultSuffix окна сохранения добавляет его, если имя введено без него.

Экспорт не открывает базы данных и не синхронизирует сад ради сохранения.
Схемы v13/v7, ревизии, кошелёк, квитанции, источники и достижения не меняются.
При выключенном учёте графика выгружена, экспорт отображаемого участка
недоступен до включения.

## Данные HTML

Инертный блок application/json с id ritm-garden содержит format=ritm-garden-1,
garden и две контрольные суммы. sha256 считается от UTF-8 строки encode_garden
(ключи сортируются, формат JSON совпадает с codec хранилища); image_sha256 —
от встроенного PNG. JSON экранирует HTML-разделители, подписи HTML экранированы.
Внешних ресурсов/исполняемых скриптов нет; CSP ограничивает страницу встроенным
изображением и стилем. Это контроль целостности, а не цифровая подпись.

## Проверенные границы

Проверены Linux/Qt Quick SaveFile, Unicode и пробелы/# в имени, отмена,
подстановка расширения, ошибки записи, перенос HTML в другую папку и frozen
месяц. Страница осмотрена в Qt WebEngine без JavaScript и доступа к удалённым
ресурсам; PNG осмотрен отдельно. Сценарий xcb использует Qt Quick picker,
GTK/Windows/macOS-системные диалоги отдельно не проверялись. Подробные числа
и ограничения — TESTING T39e3.
